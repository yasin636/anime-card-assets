R2 owner-tested and accepted. R3 is an interactive offline **design preview**, not native implementation. All names/messages/stats/ranks/dialogue/AI answers are samples and reset on reload. ## Try

Settings sheet offers simulated connection error and Retry. New clears local conversation. Navigation/background stops pending demo answer. Clipboard permission failure offers selectable text instead of false success.
- Arena → hunter profile, weekly sample board, combat presentation sheet. Buttons show selection feedback only, not a fabricated combat result/HP/score. Existing real match mechanics, authorization, cooldowns and rewards remain authoritative in native.
- Adventure → gate artwork, illustrative dialogue, Chronicle/Shadow Army sheets. Existing canonical story, theater, signature moments, ARISE eligibility and server-confirmed army are retained; no new chapter/content/reward implied. Native actual actions must match existing state, not placeholder controls.
- Motion toggle + OS prefers-reduced-motion; dialog Escape, focus trap/return. Mobile composer and nav layout proposals need native Android keyboard verification later; preview tests are not physical-device certification.
